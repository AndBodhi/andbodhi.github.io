# Bollywood Playlist Agent

A personal tool run by Padmabodhi Wasnik (pbodhi@gmail.com) to organise his own music into YouTube playlists on his own channel.

## Privacy Policy
- The tool is used only by its owner. It has no other users.
- It accesses only the owner's YouTube account, to create playlists and add videos to them.
- It does not collect, sell or share any personal data with anyone.
- Access can be revoked anytime at https://myaccount.google.com/permissions
